      Open searches in your pinned tabs

      Websites aren't allowed to use tabs you opened yourself, like your pinned Reddit tab. This small free Chrome add-on (made for Post Finder, it only works on this site) does it: a Reddit search opens in your pinned Reddit tab, an X search in your pinned X tab, and so on. No pinned tab for that site? It opens one tab and keeps reusing it.

      1. Download the helper and unzip it (right-click → Extract All).
      2. In Chrome, type chrome://extensions in the address bar and press Enter.
      3. Turn on Developer mode (top right).
      4. Click Load unpacked and pick the unzipped post-finder-helper folder.
      5. Come back here and press Ctrl+F5. You'll see a green ✓.

      Already have the helper? Version 2.1 can also read Reddit flairs. Download it again, unzip it over your post-finder-helper folder (replace the files), then click the ↻ reload arrow on Post Finder helper in chrome://extensions.

      Chrome will say it can “read your browsing history”: that's Chrome's name for seeing which tabs are open, which it needs to find your pinned Reddit / X / Facebook / Bluesky tab. It doesn't read pages, save anything or send anything anywhere, and only this website can talk to it.
