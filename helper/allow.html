Let the helper read Reddit flairs

Post Finder wants to know which flair (tag) each Reddit community gives client posts, like Hiring on r/HungryArtists, so it can show you only client posts.

To do that, the helper needs to read Reddit. It only ever reads:

  • the newest 100 posts of a community you ask about (to see their flairs), and
  • Reddit's community search, when you search for communities on the Post Finder page.

It only does this when you click on the Post Finder page. It never posts, never sends anything anywhere else, and never reads any other website.
